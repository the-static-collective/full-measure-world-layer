# STILL HERE × Full Measure · Seven Days of Returning

A small, mobile-first, self-paced, non-punitive practice room for rebuilding ordinary capacity and optionally discovering community stewardship.

**How to run:** Open the standalone `still-here-seven-days.html` directly in your browser. To serve the editable source, run `python -m http.server 8018` from this folder and visit `http://localhost:8018`.

**Tests:** `node --test core.test.mjs` (Node 22 or newer). Browser smoke-tested with Playwright/Chromium at desktop and Android-size viewports.

## Boundaries

* No accounts, contact details, journal text, names, tracking scripts, or submitted case evidence.
* A coarse `{day,area,minutes,kind}` record is kept in `localStorage` only when available; each user can clear it. No other data is stored by application code.
* Browser history, device monitoring, local storage inspection, and a web host's request metadata remain potential privacy risks.
* Rest counts as a valid return, and there is no streak, ranking, or punishment for absence.
* Private self-attested check-ins do not manufacture Full Measure Deeds, external human witnesses, or proof of service.
* The day-eight door navigates to the already-existing STILL HERE / The Porch Open Seats preview. No one is enrolled, matched, or appointed automatically. Review safeguards before any sensitive peer-support activity.
* Not a staffed service, evidence vault, legal representation, or confidential intake.

## Status

This is an independently playable prototype and an integration proposal. It has **not** been merged into Full Measure or connected to a shared organizational backend.
