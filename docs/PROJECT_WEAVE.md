# Project Weave

Full Measure is the playable world layer. It should combine proven organs from the
Static Collective ecosystem without collapsing them into one repository or one source
of authority.

## Source projects

| Project | Contribution to Full Measure | Boundary |
|---|---|---|
| [Jubilee Campfire](https://github.com/the-static-collective/Jubilee-Campfire) | Authoritative participation lifecycle: Offer, Need, Pledge, Report, Witness, Receipt, Capacity | Full Measure projects existing transitions; it must not create a parallel truth ledger |
| [BananaSpork](https://github.com/the-static-collective/BananaSpork) | Scope-first retrieval, explicit evidence, growth lanes, field capture, and the Garden doorway | Private or held drafts remain excluded from shared retrieval and generation |
| [BananaGram](https://github.com/the-static-collective/BananaGram-Gram-to-Fork) | Portable, addressable participation seeds and lightweight invitations | A transported seed is still a proposal until accepted by the relevant authority |
| [seedFORK](https://github.com/the-static-collective/seedFORK) | Lineage packets, snapshot heads, forks, active tensions, and harvest ancestry | A fork preserves provenance; it does not silently replace its source |
| [mundaneWORMHOLE](https://github.com/the-static-collective/mundaneWORMHOLE) | Structured generation from explicit excerpts with Accept, Revise, Parallel, and Unresolved dispositions | Generated material remains proposed and source-bounded |
| [reCURVrePAIR](https://github.com/the-static-collective/reCURVrePAIR) | Proposed, Held, Accepted, Declined, and Left Open states; repair scars and non-erasure | Decline and unresolved tension remain first-class history |
| [reMIX-reCURVrePAIR](https://github.com/the-static-collective/reMIX-reCURVrePAIR) | Context packets and model-turn receipts | Provider execution proves that a turn occurred, not that its claims are true |
| [the-autodisco](https://github.com/the-static-collective/the-autodisco) | Narrative voice, mutation, ceremony, soundtrack, and campaign recap | Autodisco supplies imaginative garments, never authority over canon or witnessed facts |
| [TranchNode](https://github.com/the-static-collective/tranchnode) | Meaning-bearing objects, lineage, tensions, proposals, rejections, witnesses, and harvests | Retrieval is not authority; confidence is not evidence; model output cannot silently rewrite memory |

## Current ownership map

| Concern | Canonical owner |
|---|---|
| What happened and who may attest to it | Jubilee authority and receipts |
| What an object means, cites, depends on, or leaves unresolved | TranchNode lineage |
| What might become playable next | Full Measure Dungeon Master proposals |
| Portable invitation into participation | BananaGram |
| Field capture and private drafting | BananaSpork / NanaSpork surface |
| Generative narrative texture | Autodisco and WORMHOLE-style generators |
| Song-to-video rendering | The Haunted Toaster, outside this project |

## Integration rule

Every imported capability must declare:

1. the source project and source version;
2. the objects it reads;
3. the objects it may propose;
4. the authority required to accept the proposal;
5. the receipts or lineage edges it emits;
6. private or held material it is forbidden to read.

If an integration cannot state those six things, it is not ready to enter the weave.
