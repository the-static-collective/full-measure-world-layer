# Commons Return Lens 001 — Full Measure × reLATTE × planZ

**2026-10-28. Machine-tested, read-only capacity review lens. Not live shared-mode participation or a credit-awarding adapter.**

A receiver-local reLATTE observation can HOLD, REFUSE, or ADMIT an unverified planZ return packet for review. The Full Measure lens `assessCommonsReturn` accepts only explicitly unverified candidate state and optional reLATTE transport status. It distinguishes a held/refused claim from a reviewable observation, while **always granting 0 Deeds, 0 Harvests, and 0 Capacities**.

The output identifies what is still missing for a real capacity claim: authenticated and revocable stewardship, recipient confirmation independent of the task reporter, a local Garden project/pledge/receipt connection, measurable before/after value, and source-owner/receiver review. Neither a candidate packet nor a source-key signature proves these requirements.

An authorized local Full Measure project may later link real receipts and benefits through its existing permissioned human-witness flow. This lens never manufactures a pledge, a receipt, or participant identity. No foreign information is written into the live Full Measure store. There is no direct HTTP API, global deployment, autonomous adjudication or awarding based on foreign statuses.

**Truth invariant:** `SIGNED != TRUE`; `ADMITTED_OBSERVATION != DEED`; `RETURNED_METHOD != CAPACITY`; `CAPACITY_REQUIRES_OWN_LOCAL_EVIDENCE`.
